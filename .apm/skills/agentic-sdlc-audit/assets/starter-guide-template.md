## Rendering contract

Invoke the private guide command with `--profile starter-guide`. The public dispatcher
continues to expose only `report` and `inventory`; `--format guide` remains unsupported.
The starter guide is Markdown-only stdout/chat output and is never persisted.

The command recollects strict inventory, validates the same closed proposal envelope used
by the improvement guide, builds the same remediation view, and selects the starter
renderer. Dynamic repository and operator values remain untrusted data and pass through
the shared redaction and Markdown-safety boundary.

## Deterministic sections

The starter renderer owns these sections and their ordering:

1. Beginner verdict and one next action
2. Ordered starter flow
3. `AGENTS.md` versus `.github/copilot-instructions.md`
4. Cost per trusted merged outcome
5. What to share for implementation
6. Implementation recommendations
7. Unknowns and verification steps
8. Do not do yet
9. Source registry

## Starter boundaries

The ordered flow is deliberately small: frame one bounded task, start with narrow
context, add one concise instruction surface, make setup and focused validation
deterministic, keep review human-owned with a bounded pull request, and measure retries,
CI, review, rework, risk, and the merged outcome.

Instruction-file guidance is selected from observed repository shape and existing files.
It never emits a generic instruction template. Unknown team, plan, risk, network,
command, prior-use, task-owner, and baseline facts remain `UNVERIFIED`.

The economic objective is cost per trusted merged outcome:

```text
AI usage + CI + interaction + review + rework + operational risk
```

Token minimization alone is not an optimization. Numeric ROI, savings, or productivity
claims require local baseline, cost, attribution, and completed-outcome evidence.
Multi-agent orchestration is explicitly deferred. Proposal identifiers, control
categories, and recommendation text that request orchestration or agent fan-out are
rejected before the starter guide can render.
